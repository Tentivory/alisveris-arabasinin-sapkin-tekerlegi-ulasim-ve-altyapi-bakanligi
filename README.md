# alisveris-arabasinin-sapkin-tekerlegi-ulasim-ve-altyapi-bakanligi
Alışveriş arabasının tek tekerleğinin sapıtmasını resmi ulaşım kazası, milli teker egemenliği ihlali ve reyon protokolü sapması sayan; sepeti fil, 'biraz iterim düzelir' cümlesini yol yapım ihalesi ilan eden Bakanlık. Gerçekten çalışır. Arabalar artık hattır.
